# STM32 麦轮底盘实验接口与采集说明

署名：JHY；验证日期：2026-10-26。

## 1. 固件范围

本工程保留 STM32F407、四个 M3508/C620、CAN1 及原轮序 LF、LB、RB、RF，新增 `app_experiment` 监督实验接口。TIM8 按 1 kHz 执行健康检查、逆运动学和四轮速度 PID，主循环处理命令及遥测输出。上电默认为停机状态，不自动使能电机。

本次完成了编译、链接和 PID 算术回归检查，未连接底盘、未烧录、未采集实车数据。`Simulation` 中的输出是软件仿真数据，不能填写为实测结果。

## 2. 构建与验证证据

所需工具为 ARM GCC、CMake 3.22 或以上版本及 Ninja。若工具已加入 PATH，在工程根目录运行：

```powershell
./JHY/Build-Firmware.ps1 -Configuration Debug
./JHY/Build-Firmware.ps1 -Configuration Release
```

若 CMake/Ninja 未加入 PATH，可以显式指定路径。本机验证使用：

```powershell
./JHY/Build-Firmware.ps1 -CMake 'D:/CLion/CLion 2025.3.1/bin/cmake/win/x64/bin/cmake.exe' -Ninja 'D:/CLion/CLion 2025.3.1/bin/ninja/win/x64/ninja.exe' -Configuration Debug
```

脚本选择未被占用的 T: 至 Z: 盘符建立临时 ASCII 路径，以绕过本机 CMake 在中文工作目录中的异常；完成后仅清理本次创建的映射，不改动已有映射。构建目录为 `build/JHY_<配置>_<盘符>`，脚本最后打印 ELF 的真实路径。该脚本只构建，不烧录。

实际工具为 ARM GCC 13.3.1、CMake 4.1.2、Ninja。Debug 与 Release 均完成 37 个编译/链接任务，退出码为 0，无编译警告。链接器统计如下：

| Debug | 53,532 B | 6,400 B | 0 B |

已用 ELF 符号表确认 `_printf_float` 与 `_scanf_float` 均已实际链接，串口 CSV 浮点格式化及浮点参数解析不会依赖 newlib-nano 默认关闭的浮点支持。

对应产物为 `build/JHY_Debug_T/Mecanum_Wheel_Chassis.elf` 和 `build/JHY_Release_T/Mecanum_Wheel_Chassis.elf`。这只能证明构建成功，不代表控制实时性、接线方向或实车稳定性已通过测试。

## 3. 实验系统搭建

主控按原工程接入 CAN1，四个电调的反馈 ID 依次为 `0x201`、`0x202`、`0x203`、`0x204`，电流指令帧为 `0x200`。检查电源极性、额定电压、电流限制、CAN 终端电阻和接地，再在车轮架空、低速且有人值守的条件下逐轮确认转向。

底盘默认几何量为半宽 `a=0.215 m`、半长 `b=0.2215 m`、轮半径 `R=0.077 m`；轮速限制为 `15 rad/s`，减速比为 `3591/187`。实车几何、滚子排列与电机方向必须按实际装配核验。新增接口保留原固件四路目标轮速统一取负号的接线约定，不能仅根据注释直接推断实车轴向。

USART1 为 `420000 baud、8N1、无硬件流控`，TX 为 PA9、RX 为 PB7；使用匹配的 3.3 V USB 转串口并共地。输出可由根目录 `tools/Capture-Telemetry.ps1` 监听保存，采集脚本不自动发送 ARM。读取数据前确认串口工具不会向主控注入额外字符。

独立物理急停需要由电源/驱动使能回路实现。此工程没有接入急停按钮 GPIO、制动器、IMU 或外部定位设备；串口 `ESTOP` 只是软件命令。

## 4. 文本命令与参数调整

每条命令使用 ASCII，大写操作名，以换行符 LF 结束；CRLF 也可。单条命令少于 100 字节，不使用多余后缀。命令由主循环解析后，在短临界区一次性提交给控制中断。

| 命令 | 作用及条件 |
| --- | --- |
| `STOP` | 停机，清零目标、PID 积分与四轮输出；不清除故障锁存。 |
| `RESET` | 停机并重新检查健康状态；当前仍存在的离线、过温、超速等故障不会被清除。不会自动使能。 |
| `ARM` | 仅在无故障且四轮反馈有效时使能；先清零所有目标，再进入使能状态。 |
| `SET vx vy omega` | 更新底盘目标，单位为 m/s、m/s、rad/s；要求有限数，`abs(vx),abs(vy)<=3`、`abs(omega)<=6`。轮速还会等比例限幅。 |
| `KEEP` | 刷新命令看门狗，不改变目标；运行中需至少每 500 ms 刷新一次。 |
| `ESTOP` | 软件急停并锁存故障位 32；排查后先 RESET，再手动 ARM。 |
| `PID kp ki kd` | 仅停机时设置四轮共用 PID 增益；范围分别为 0..10000、0..1000、0..1000。不自动保存到 Flash。 |
| `GEOM a b R` | 仅停机时改几何参数，范围为 a/b=0.01..1 m、R=0.01..0.5 m。不自动保存到 Flash。 |

低速试验时，在完成架空检查且四轮状态正常后，依次发送 `RESET`、`ARM`，再发送例如 `SET 0.05 0 0`，随后持续发送 KEEP 或新的 SET。ARM 前设置的运动目标会在 ARM 时清零；停机状态下不会保留供下次自动执行。结束时发送 STOP，再切断驱动电源。

运行中可用 SET 调整速度；几何量和 PID 必须先 STOP 再调整。掉线、过温或输入错误解除后需要 RESET 与 ARM 两个显式步骤，不会自行恢复运行。

## 5. 安全联锁及其范围

| fault 位值 | 含义与默认判据 |
| --- | --- |
| 1 | 任一轮从未收到有效反馈，或反馈年龄超过 100 ms。 |
| 2 | 任一轮反馈温度达到 70 °C。 |
| 4 | 任一轮实际轮速超过 `1.2*max_omega`，默认 18 rad/s。 |
| 8 | 非有限值、非法参数/命令、UART 接收溢出或串口错误等。 |
| 16 | 使能后超过 500 ms 没有收到有效 SET/KEEP。 |
| 32 | 收到软件 ESTOP。 |
| 64 | 使能时 CAN 发送调用失败。 |

fault 是位掩码，多种故障可相加。使能状态检测到故障时，1 kHz 控制回路将四轮目标、积分和待发送电流全部清零，转入停机并锁存。停机状态仍报告实时健康异常，例如上电未接电机时出现位 1。RESET 后健康条件仍不满足时不能 ARM。

CAN 发送失败会记录计数并清零软件发送缓冲区；如果总线断开或电调失效，软件无法保证零电流命令送达，也不能保证机械立即停止。该机制依赖电调自身的通信保护与独立物理急停。70 °C、100 ms 等是课程实验默认值，需根据实际硬件和实验风险重新核定。

## 6. 实时采集、队列与字段

每 20 个 TIM8 控制周期采集一次快照，即标称 50 Hz。16 槽环形队列保留一个空槽，可缓存 15 帧；队列满时丢弃新帧并增加 `dropped`，不会阻塞控制中断。主循环在 DMA 空闲时格式化并发送 CSV；中断中不调用 printf、sscanf 或阻塞串口发送。数据带主控毫秒时间戳，可据此检查断帧及实际采样间隔。

USART 接收采用中断和 256 字节环形缓冲，主循环解析命令，避免格式化遥测时仅靠轮询丢失字符。USART1 IRQ 优先级为 2，可抢占优先级为 3 的 TIM8；CAN 接收优先级为 1。RX 溢出或 UART 错误时丢弃受损命令行并进入输入故障处理。实际最坏中断耗时和总线负载仍需用逻辑分析仪实测。

发送端启动时及之后每 5 s 重复 CSV 表头，允许先启动主控后开启采集；分析工具应识别并跳过重复表头。

```text
ms,armed,fault,dropped,can_errors,command_errors,LF_target,LB_target,RB_target,RF_target,LF_omega,LB_omega,RB_omega,RF_omega,LF_current_raw,LB_current_raw,RB_current_raw,RF_current_raw,LF_temp_C,LB_temp_C,RB_temp_C,RF_temp_C,LF_age_ms,LB_age_ms,RB_age_ms,RF_age_ms
```

| 列组 | 含义/单位 |
| --- | --- |
| ms | 主控 HAL 毫秒计数，32 位回绕；采集后按无符号差值计算间隔。 |
| armed、fault | 使能标志和故障位掩码。 |
| dropped | 遥测快照丢弃累计数。 |
| can_errors、command_errors | CAN 发送错误和命令/接收错误累计数；错误计数用于诊断。 |
| 四列 target | 电机输出轴目标角速度，rad/s，带原接线符号。 |
| 四列 omega | 减速比换算后的电机输出轴实测角速度，rad/s。 |
| 四列 current_raw | C620 原始反馈电流计数；尚未标定为 A 或 N·m。 |
| 四列 temp_C | 电机反馈温度，°C。 |
| 四列 age_ms | 最近有效反馈的年龄；从未反馈时为 4294967295。 |

所有四轮列均按 LF、LB、RB、RF 排列。CAN 接收入口校验标准数据帧及 DLC=8，HAL 取帧失败时不再解析旧缓冲区。原驱动保留 `Now_Torque` 和相关 getter 名称以兼容其他代码，但其值仍是原始反馈计数，不能以函数名推断物理扭矩。

## 7. 本次关键修正和实测后续

应用层目录及个人创建署名统一为 JHY；第三方 CMSIS/HAL 版权未修改。原运动学头文件去除不必要的 HAL 与旋转矩阵依赖，使固件和 PC 仿真直接编译同一份逆运动学 C 源码。原始压缩包和 Git 历史未改写。

固件调整了启动顺序，先初始化电机、PID 和实验接口，再启动 CAN 与 TIM8，避免初始化完成前控制中断访问电机。PID 修正了 Ki=0 时积分限幅除零问题，并改为积分更新后限幅；非法采样周期和非有限输入返回零输出，电机打包前再次检查并限幅，避免非有限浮点数直接转整数。

后续实物验收应独立完成：核验轮向与坐标、用测速/定位设备标定轮径和滑移、用已知电流标定反馈计数、测量 TIM8 最坏耗时、断开单轮 CAN 观察全轮停机、验证过温阈值及串口看门狗，并核对 `dropped`、错误计数和采样周期。为避免误判，真实轨迹精度需要外部定位参考；仅由电机编码器积分不能验证地面真实位移。
